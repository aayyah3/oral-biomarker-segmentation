# Oral Biomarker Segmentation

Undergraduate research project benchmarking U-Net and pretrained segmentation 
models (MedSAM, HoVer-Net) on multimodal oral histology images (HE and DFIR).

## Structure
- `data/` — marker images and GT masks (gitignored, not pushed to GitHub)
- `notebooks/` — visualization and exploration
- `src/` — model, dataset loader, training scripts
- `outputs/` — saved weights and predictions
